# 📊 Руководство по работе с турнирной таблицей

## 📝 Как добавить результаты матчей

### Способ 1: Через функцию `updateMatchResult()`

**ВАЖНО: Всегда указывайте счет всех 3 партий!**

```javascript
// updateMatchResult(matchId, homeSets, awaySets, setScores)

// Пример 1: Макиато победил Dream team 3-0
updateMatchResult(1, 3, 0, [
    { home: 25, away: 22 },
    { home: 25, away: 20 },
    { home: 25, away: 18 }
]);

// Пример 2: Серволюкс победил Сетка 37 2-1
updateMatchResult(2, 2, 1, [
    { home: 25, away: 23 },
    { home: 22, away: 25 },
    { home: 25, away: 21 }
]);

// Пример 3: Могилевгражданпроект проиграл Отцы и дети 1-2
updateMatchResult(3, 1, 2, [
    { home: 25, away: 27 },
    { home: 25, away: 22 },
    { home: 20, away: 25 }
]);

// Пример 4: Могилевгипрозем проиграл 33 0-3
updateMatchResult(4, 0, 3, [
    { home: 20, away: 25 },
    { home: 23, away: 25 },
    { home: 18, away: 25 }
]);
```
## 🏆 Критерии сортировки таблицы

Тай-брейк: очки → победы → разница партий → партий выиграно → разница мячей → мячей забито

Команды сортируются по следующим критериям (в порядке приоритета):

1. **Турнирные очки** ⭐ (главный критерий)
2. **Количество побед**
3. **Разница партий** (+/-)
4. **Количество выигранных партий**
5. **Разница очков в партиях**
6. **Количество выигранных очков в партиях**

## 📊 Отображение на странице

### Турнирная таблица показывает:

| Колонка | Значение | Описание |
|---------|----------|----------|
| **#** | Позиция | Место в таблице |
| **Команда** | Название | Название команды |
| **И** | Игры | Сыграно матчей |
| **Партии** | X-Y | Выиграно-Проиграно партий |
| **+/-** | Разница | Разница партий |
| **Очки** | Баллы | Турнирные очки (главное!) |

## 💻 Примеры использования

### Добавить результат одного матча:

```javascript
// Матч #1: Макиато vs Dream team (3-0)
updateMatchResult(1, 3, 0, [
    { home: 25, away: 22 },
    { home: 25, away: 20 },
    { home: 25, away: 18 }
]);
```

### Добавить результаты целого тура:

```javascript
// Тур 1 (всегда 3 партии в каждом матче!)
updateMatchResult(1, 3, 0, [
    { home: 25, away: 22 }, 
    { home: 25, away: 20 }, 
    { home: 25, away: 18 }
]);
updateMatchResult(2, 2, 1, [
    { home: 25, away: 23 }, 
    { home: 22, away: 25 }, 
    { home: 25, away: 21 }
]);
updateMatchResult(3, 1, 2, [
    { home: 25, away: 27 }, 
    { home: 25, away: 22 }, 
    { home: 20, away: 25 }
]);
updateMatchResult(4, 0, 3, [
    { home: 20, away: 25 }, 
    { home: 23, away: 25 }, 
    { home: 18, away: 25 }
]);
```
